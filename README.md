# ⚛ QuantumDx – Quantum AI Medical Imaging

A hybrid quantum–classical system that screens **chest X-rays for pneumonia**. A 6-qubit variational quantum circuit is trained and tested on the real **PneumoniaMNIST** dataset, and the same circuit runs live in the browser on a multi-page website where you can upload an X-ray and get a result.

> Research / educational prototype. **Not a medical device.** Never use it for diagnosis or treatment decisions.

![home](docs/screenshot-home.png)

## Results (real test set, 624 X-rays)

| Metric | Quantum circuit (6 qubits, 18 params) | Logistic regression (same features) |
|---|---|---|
| Accuracy | **83.2 %** | 87.3 % |
| ROC-AUC | 0.924 | 0.947 |
| Sensitivity | 92.8 % | 91.8 % |
| Specificity | 67.1 % | 79.9 % |

Confusion matrix (test): TN 157 · FP 77 · FN 28 · TP 362. Train / validation accuracy: 88.7 % / 88.4 %.
The quantum circuit is competitive but **does not beat the classical baseline**, and it is **simulated on a classical computer**, not run on quantum hardware. The random seed and decision threshold were chosen on validation data only. The circuit size (6 qubits, 3 layers) was picked during exploratory runs that also looked at test accuracy, so the test figure may be slightly optimistic.

## How it works
1. Resize the X-ray to 28×28 grayscale.
2. Extract 6 features (mean, contrast, edge energy, lower/upper, left/right and centre brightness) and scale them to [0, π].
3. Encode feature *k* as `RY` on qubit *n-1-k*, apply 3 layers of trainable `RY(θ)` + a CNOT ring.
4. Measure ⟨Z⟩ on qubit 0: `P(pneumonia) = (1 − ⟨Z₀⟩) / 2`.
5. Training: parameter-shift gradients + Adam, class-weighted loss, 4 random starts, best chosen on validation.

## Repository layout
```
index.html            website (6 pages: Home, Dataset, Model, Results, Diagnose, About)
css/style.css         styling (light/dark theme)
js/quantum.js         quantum circuit simulator + feature extraction (JS)
js/app.js             website logic
js/results.js         trained weights + results (generated by python/train.py)
python/qsim.py        quantum simulator + classifier (NumPy)
python/train.py       train + validate + test + export
python/pennylane_check.py  optional cross-check against PennyLane
tests/test_simulator.py    unit tests for the simulator
data/pneumoniamnist.npz    dataset (MedMNIST, CC BY 4.0)
results/              metrics.json, training_log.txt, training_results.png
docs/                 screenshots
```

## Run the training and testing
```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r python/requirements.txt
python tests/test_simulator.py                          # 4 unit tests
python python/train.py --data data/pneumoniamnist.npz   # ~40 s, rewrites results + js/results.js
```
Options: `--qubits 6 --layers 3 --steps 120 --seeds 4`. The script prints the full train / validation / test report and saves `results/training_log.txt`.

## Run the website locally
Just open `index.html` in a browser (no server or build step needed), or:
```bash
python -m http.server 8000     # then visit http://localhost:8000
```

## Deploy on GitHub Pages
1. Create a GitHub account and a **new public repository** named `quantum-dx` (don't add a README, we already have one).
2. In this folder run:
   ```bash
   git init
   git add .
   git commit -m "Quantum AI medical imaging system"
   git branch -M main
   git remote add origin https://github.com/<your-username>/quantum-dx.git
   git push -u origin main
   ```
   (If asked for a password, use a GitHub Personal Access Token, or sign in via GitHub Desktop / `gh auth login`.)
3. On GitHub open **Settings → Pages**. Under *Build and deployment*, set **Source: Deploy from a branch**, **Branch: main**, folder **/ (root)**, then **Save**.
4. After 1–2 minutes your site is live at **`https://<your-username>.github.io/quantum-dx/`**.
5. Replace `YOUR-USERNAME` in `index.html` (the GitHub button) and `YOUR NAME` in `LICENSE`, then commit and push again.

No-terminal alternative: on GitHub choose **Add file → Upload files**, drag in everything from this folder, commit, then do step 3.
